# Использованные источники

## 1.1 Характеристика предметной области и объекта автоматизации

1. Mach3Mill Install and Config Guide. — ArtSoft USA. — URL: <https://www.machsupport.com/wp-content/uploads/2013/02/Mach3Mill_Install_Config.pdf> (дата обращения: 22.11.2026).

   Руководство подтверждает обработку команд G-кода программой Mach3 и формирование сигналов STEP/DIR при подключении станка через параллельный порт.

## 1.2 Анализ существующего процесса и построение целевой модели

1. Материалы проекта VISOR. [Контекст проекта](Контекст.md), разделы 3 и 7–9. Исходные сведения об участке уточнены 12.11.2026.

2. Object Management Group. Business Process Model and Notation (BPMN). Version 2.0.2. — 2014. — URL: <https://www.omg.org/spec/BPMN/2.0.2/PDF> (дата обращения: 22.11.2026).

   Спецификация использована при оформлении дорожек, задач, событий и потоков управления на рисунке 1.1.
